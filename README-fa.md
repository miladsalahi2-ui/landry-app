# 🧺 لندری من — نسخه اندروید (APK)

نرم‌افزار مدیریت لندری و یادآوری کارهای روزانه — **کاملاً آفلاین**، داده‌ها روی خود گوشی ذخیره می‌شود و به هیچ سروری وصل نیست.

---

## 📦 سه راه برای گرفتن APK

### روش ۱ — بدون نصب هیچ ابزاری (پیشنهادی): GitHub Actions

1. یک حساب [github.com](https://github.com) داشته باشید
2. مخزن (Repository) جدید و عمومی بسازید (مثلاً `landry-app`)
3. همه فایل‌های همین پوشه را آپلود کنید (از دکمه **uploading an existing file** یا با git)
4. به تب **Actions** بروید → بیلد «Build APK» خودکار اجرا می‌شود
5. بعد از ۲ تا ۳ دقیقه روی بیلد کلیک کنید → از بخش **Artifacts** فایل `landry-app-debug-apk` را دانلود کنید
6. فایل zip شامل `app-debug.apk` است — آن را به گوشی بفرستید و نصب کنید

> برای اجرای مجدد: تب Actions → «Build APK» → دکمه «Run workflow»

### روش ۲ — Android Studio

1. آخرین نسخه [Android Studio](https://developer.android.com/studio) را نصب کنید
2. **Open** → همین پوشه (`landry-app`) را باز کنید و اجازه دهید Sync کامل شود
3. از منو: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود

### روش ۳ — خط فرمان (بدون Android Studio)

پیش‌نیاز: JDK 17 + Android SDK (یا فقط `cmdline-tools`)

```bash
# یک بار: نصب Gradle 8.5 یا استفاده از gradlew
gradle assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

## 📲 نصب روی گوشی

1. فایل `app-debug.apk` را به گوشی منتقل کنید (تلگرام، کابل، ...)
2. روی فایل بزنید — اگر پیام «نصب از منابع ناشناس» آمد، برای همین برنامه مجوز دهید
3. نصب را تأیید کنید — آیکون «لندری من» روی صفحه اصلی ظاهر می‌شود

> این APK نسخه **Debug** است و امضای توسعه‌دهنده دارد؛ برای انتشار در کافه‌بازار/مایکت یا گوگل‌پلی باید نسخه **Release امضاشده** بسازید (در Android Studio: Build → Generate Signed Bundle/APK).

## 🗄 داده‌ها کجا ذخیره می‌شوند؟

داده‌ها در `localStorage` خود WebView گوشی ذخیره می‌شوند (مشابه حافظه اپ‌های معمولی).
- **پاک کردن داده برنامه** از تنظیمات اندروید = حذف داده‌ها! پس هر از چند گاهی **پشتیبان بگیرید** (دکمه ⬇ در هدر برنامه).
- برای انتقال به گوشی جدید: خروجی بگیرید → در گوشی جدید بازیابی کنید.

## 🛠 معماری فنی

- `app/src/main/assets/www/` — وب‌اپ مستقل (HTML/CSS/JS خالص، بدون وابستگی اینترنتی)
- `MainActivity.kt` — WebView با `WebViewAssetLoader` (origin امن https برای localStorage پایدار)
- `minSdk 24` (اندروید ۷ به بالا) — در صورت نیاز WebView از پلی‌استور به‌روزرسانی می‌شود
- `web/` — همان وب‌اپ برای استفاده مستقیم در مرورگر (فایل index.html را باز کنید)

## 🔄 به‌روزرسانی محتوای اپ

اگر فایل‌های `web/` را تغییر دادید، همان‌ها را در `app/src/main/assets/www/` هم کپی کنید (یا خود پوشه web را داخل assets بازسازی کنید) و دوباره APK بسازید.
